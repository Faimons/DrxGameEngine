## 🚀 Quick Start

### 1. Extract Archive
```bash
tar -xzf drx-engine-master-v1.0.0.tar.gz
cd drx-engine-master
```

### 2. Review Documentation
```bash
# Start here
cat README.md

# Then read the master plan
cat DRX_ENGINE_WHITEPAPER.md

# Quick start guide
cat QUICKSTART.md
```

### 3. Install Dependencies
```bash
# Ubuntu/Debian
sudo apt-get install build-essential cmake git python3 \
    libvulkan-dev vulkan-tools libglfw3-dev

# Python
cd AI
pip3 install -r requirements.txt
```

### 4. Build Project
```bash
./build.sh
```
